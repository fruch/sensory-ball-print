# התקנת Python (בשביל כלי העזר)

**לא צריך את זה כדי להדפיס את הכדור.** זה רק בשביל שני כלי עזר:

- הסקריפט `tools/check_fit.py` - בודק ששלושת הקבצים שקיבלתם מתאימים זה לזה
- הסקריפט `tools/extract_ball.py` - מוציא קבצים בצבע אחד מתוך הפרויקט הצבעוני

שניהם תוכניות **Python**. ‏Python היא תוכנה חינמית שמריצה תוכניות קטנות אחרות (שנקראות סקריפטים). את הפקודות מקלידים ב**טרמינל** - חלון שבו מקלידים במקום ללחוץ.

## Windows

### 1. מתקינים Python

1. פתחו את **Microsoft Store** (לחצו על התחל והקלידו `store`).
2. חפשו **Python 3.13** (או את ה-**Python 3.x** הכי חדש שמופיע).
3. לחצו **Get** (או **Install**). חכו עד שזה מסתיים.

אין לכם Microsoft Store? השתמשו בהתקנה מהאתר [python.org/downloads](https://www.python.org/downloads/). במסך הראשון של ההתקנה, **סמנו את "Add python.exe to PATH"** לפני שאתם לוחצים **Install Now**. אם שוכחים את זה, הפקודות שבהמשך לא יעבדו.

### 2. פותחים טרמינל בתיקיית הפרויקט

1. פתחו את התיקייה שבה חילצתם את הפרויקט (זו שיש בתוכה תיקייה בשם `tools`).
2. לחצו על **שורת הכתובת** למעלה בחלון התיקייה.
3. הקלידו `powershell` ולחצו **Enter**. ייפתח חלון כחול או שחור - זה הטרמינל, והוא כבר "בתוך" התיקייה שלכם.

(ב-Windows 11 אפשר גם ללחוץ קליק ימני על מקום ריק בתיקייה ← **Open in Terminal**.)

### 3. בודקים ש-Python עובד

הקלידו את זה ולחצו **Enter**:

```
python --version
```

אמור להופיע משהו כמו `Python 3.13.1`. אם כתוב שהפקודה לא נמצאה, סגרו את הטרמינל ופתחו אותו מחדש. עדיין לא עובד? התקינו Python שוב, ותוודאו ש-"Add python.exe to PATH" מסומן.

### 4. מריצים כלי

ב-Windows הפקודה היא `python`, ובין תיקיות כותבים `\`:

```
python tools\check_fit.py half1.stl half2.stl screw.stl
```

אם בשם של קובץ יש רווחים, שימו אותו במירכאות: `"Sensory Screw V11.stl"`.

## Mac

### 1. פותחים טרמינל

לחצו **Cmd + Space**, הקלידו `Terminal` ולחצו **Enter**.

### 2. בודקים (או מתקינים) Python

הקלידו את זה ולחצו **Enter**:

```
python3 --version
```

- אם מופיע משהו כמו `Python 3.9.6` או חדש יותר - אתם מוכנים.
- אם קופץ חלון שאומר שצריך **command line developer tools**, לחצו **Install** וחכו (זה יכול לקחת 10-20 דקות). אחר כך הקלידו את הפקודה שוב.

### 3. נכנסים לתיקיית הפרויקט

1. הקלידו `cd ` (האותיות c ו-d, ואחריהן **רווח**). עוד לא לוחצים Enter.
2. גררו את תיקיית הפרויקט (זו שיש בתוכה `tools`) מ-Finder אל חלון הטרמינל. הנתיב שלה יופיע אחרי `cd `.
3. לחצו **Enter**.

### 4. מריצים כלי

```
python3 tools/check_fit.py half1.stl half2.stl screw.stl
```

אם בשם של קובץ יש רווחים, שימו אותו במירכאות: `"Sensory Screw V11.stl"`.

## Linux

‏Python 3 כבר מותקן. פתחו טרמינל בתיקיית הפרויקט והשתמשו ב-`python3`, כמו ב-Mac.

## טיפ: נתיבים של קבצים

הכלים צריכים למצוא את קבצי ה-‎`.stl` / ‎`.3mf` שלכם. הדרך הכי קלה: במקום להקליד שם של קובץ, **גררו את הקובץ מחלון התיקייה אל הטרמינל**. ככה הנתיב המלא שלו מודבק, עם מירכאות אם צריך (ב-Windows: החזיקו **Shift**, קליק ימני על הקובץ ← **Copy as path**, ואז הדביקו).

## למתחזקים: bash

הסקריפט `tools/verify-presets.sh` הוא סקריפט **bash**. הוא מריץ את גרסת ה-Linux של OrcaSlicer, ולכן הוא צריך **Linux**:

- **ב-Linux:** מריצים אותו כמו שהוא.
- **ב-Windows:** מתקינים WSL (‏Linux בתוך Windows): פותחים PowerShell **כמנהל** (as administrator), מריצים `wsl --install`, מפעילים מחדש את המחשב, ומשתמשים באפליקציית **Ubuntu** שמופיעה. מורידים את קובץ ה-‎`.AppImage` של OrcaSlicer ל-Linux בתוך Ubuntu.
- **ב-Mac:** לא נתמך - הסקריפט משתמש ב-OrcaSlicer של Linux. השתמשו במחשב Linux או במכונה וירטואלית של Linux.

מתנדבים אף פעם לא צריכים את הסקריפט הזה.
